2. [med] `infra/email_receipt_inbox/infrastructure.py:203-225` and `lambdas/handler.py:106-168` — Public ingress has no compute or message-size bound. SES permits S3-delivered messages up to 40 MB, while this 256-MB function holds the raw bytes, parsed MIME tree, sometimes a normalized copy, and parser-specific representations simultaneously; a mail flood can also consume the account’s shared Lambda concurrency. Add a pre-parse size quarantine/rejection, set a small `reserved_concurrent_executions` cap, and configure a finite `maximum_event_age_in_seconds`. [SES S3 limits](https://docs.aws.amazon.com/ses/latest/dg/receiving-email-action-s3.html), [Lambda concurrency](https://docs.aws.amazon.com/lambda/latest/dg/lambda-concurrency.html)
