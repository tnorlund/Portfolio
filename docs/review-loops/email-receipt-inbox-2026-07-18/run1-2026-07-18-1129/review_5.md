1. [med] `infra/email_receipt_inbox/infrastructure.py:306` — `external_active_rule_set=True` publishes MX without ensuring this component’s rule set is active. The store rule is always created inside the component’s new `rule_set`, so it cannot be “merged” into a different externally managed set, and the boolean provides no dependency on external activation. Mail can therefore be routed to an unrelated active set and dropped. Either remove this mode, or accept an existing rule-set name plus an external activation resource and make the MX record depend on that activation.
