1. [med] `infra/email_receipt_inbox/infrastructure.py:210` — The concurrency cap is not lossless as claimed. During a sustained public mail flood, queued Lambda events older than `maximum_event_age_in_seconds=3600` move to an unmonitored SQS destination; there is no alarm, consumer, replay path, or exported queue identifier, and those records expire after 14 days. Add a CloudWatch alarm plus automated redrive/replay from `raw/`, or place SQS between S3 and Lambda so reserved concurrency provides durable backpressure.

2. [low] `infra/email_receipt_inbox/infrastructure.py:233` — The S3 invoke permission restricts `source_arn` but omits `source_account`. S3 bucket ARNs contain no account ID, so another account could invoke the function if it acquired the bucket name after deletion. Add `source_account=account_id` to `aws.lambda_.Permission`.
